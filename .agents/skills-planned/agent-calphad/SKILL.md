# Agent CALPHAD

Use this skill for computational thermodynamics tasks involving phase diagrams, Gibbs energy models, and database-driven predictions.

## Goal

Guide users through reliable CALPHAD analysis and interpretation with transparent assumptions and data dependencies.

## Workflow

1. Identify target alloy/system, composition range, temperature/pressure domain, and desired outputs.
2. Select suitable thermodynamic/kinetic databases and modeling settings.
3. Run or outline equilibrium/non-equilibrium calculation steps.
4. Interpret phase fractions, transitions, and sensitivity to input choices.

## Tool Use Guidance

- Prefer validated databases appropriate to the chemical system.
- Distinguish equilibrium predictions from process-path outcomes.
- Call out when additional mobility or experimental data is needed.

## Output Requirements

- Provide concise setup guidance and interpretation notes.
- Include explicit composition and temperature ranges used.
- Highlight uncertainty due to database coverage or extrapolation.
