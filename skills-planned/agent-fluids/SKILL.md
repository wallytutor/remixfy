# Agent Fluids

Use this skill when the task centers on fluid flow, transport, turbulence, or CFD process guidance.

## Goal

Provide technically sound fluid-engineering guidance and actionable modeling steps appropriate to the user's fidelity and timeline.

## Workflow

1. Clarify geometry, flow regime, boundary conditions, and target outputs.
2. Select appropriate equations/models and justify assumptions.
3. Recommend simulation or calculation steps and validation checks.
4. Summarize limitations, uncertainty sources, and next refinements.

## Tool Use Guidance

- Start with the simplest model that can answer the question.
- Keep units explicit and consistent in all calculations.
- Flag when additional material properties or boundary data are required.

## Output Requirements

- Provide structured engineering recommendations.
- Include key governing parameters and dimensionless numbers when relevant.
- Clearly separate assumptions, results, and confidence level.
